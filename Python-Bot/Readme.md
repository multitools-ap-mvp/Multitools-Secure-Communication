# A Selfhosted Python Invite Bot

**Python Bot that generates a secure connect link** 

**Host & Share a encrypted key exchange with a friend**

---

## Build 

Python3 
vent v 
EAS 2048Kbit 
Python http server 

---

### Usage

1. Boot up your Bot
2. Press Start Host (Create a 1 Time Virtual Environment)
3. Press Generate Connect Link (24 Letter String created with base64)
4. Press Share Link (Send Link Securely With A Burner Mail)
5. When a user connect to the Environment a popup window loads
6. Use the Menu to exchange Keys for client handshake
7. When handshake is complete select Add Friend to exchange a cryptographic key to boot a WebSocket connection between the clients
   * Keys are valid for 24Hours. After that a new handshake needs to be exchanged
